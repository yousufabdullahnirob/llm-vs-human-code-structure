# Selected Files

## OpenMetadataApplication.java
Main entry point of the Spring Boot application.

## EntityResource.java
REST API controller responsible for handling HTTP requests.

## EntityService.java
Contains business logic for metadata operations.

## EntityRepository.java
Repository layer responsible for database communication.

## Entity.java
Represents metadata entities used throughout the system.

## CollectionDAO.java
Provides database access methods.

## JsonUtils.java
Contains helper methods for JSON processing.

## ExceptionHandler.java
Handles application-wide exceptions.
